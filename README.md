# KAVORA
Corrected KAVORA starter using the supplied KAVORA artwork.

Run:
1. `npm install`
2. `npm start`
3. Open `http://localhost:10000`

Or double-click `START-KAVORA.bat`.

The supplied artwork is used for the favicon, KAVORA logo, KAVORA Studio logo, and supporting icons. Do not open `public/index.html` directly if you want the server/API/Studio features.
